Hospital Data Analytics

Hospital Data Analytics is a data analysis and visualization project designed to study hospital patient data and understand overall hospital performance. The project uses a dataset of 1,000 patient records containing details such as age, gender, city, department, doctor, disease, admission and discharge dates, length of stay, bill amount, insurance type, payment mode, patient satisfaction, and readmission status.

The project follows a complete data analytics workflow, starting with data cleaning and preprocessing. Python is used to explore the dataset, handle data-related issues, perform calculations, and identify important patterns. Pandas and NumPy are used for data manipulation and analysis, while Matplotlib and Seaborn are used to create charts and visualizations.

Different aspects of the hospital are analyzed, including patient demographics, department-wise performance, disease distribution, revenue generation, billing, length of stay, readmission rates, and patient satisfaction. The analysis helps identify high-volume departments, common diseases, major revenue-generating areas, and areas that may require improvement.

An interactive Power BI dashboard is also developed to present important KPIs, charts, trends, and comparisons in a simple and understandable way. The dashboard makes it easier for hospital management to monitor performance and understand the key findings.

Overall, this project demonstrates the practical use of Python and Power BI in healthcare data analytics. It converts raw patient data into meaningful insights that can support better resource allocation, improved patient care, financial planning, operational efficiency, and data-driven decision-making.
